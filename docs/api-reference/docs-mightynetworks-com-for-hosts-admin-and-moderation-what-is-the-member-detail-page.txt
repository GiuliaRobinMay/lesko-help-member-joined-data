Admin and Moderation
What is the Member Detail Page?
Copy page Copy page
Copy page Copy page
The Member Detail Page is available on the Launch Plan and higher. It gives Network Hosts and Network moderators an internal view of a specific member, moderator, or Host
​
What You’ll Find on the Member Detail Page
​
Member Information Tab
This tab includes key details about the person’s activity and profile:
Last active date
The date they joined your Mighty Network
Membership type (Full or Limited)
Network role
AssignedTags
AssignedBadges
Mini bio
Custom Fields
Location
About Me
People they have referred
​
Plans and Access Tab
This tab shows:
Current and past subscriptions
All purchases
​
Available Actions
From the Member Detail Page, you can:
Message the person to open a direct message
View Profile to see their public-facing profile page
​
How to Find the Member Detail Page
Network Hosts and Network moderators can access the Member Detail Page in several ways:
​
From Admin
Select your profile photo in the upper-right corner.
Choose Admin .
Scroll to the Members section.
Select Member List .
Choose a person’s name to open their detail page, or select the three-dot menu and choose View Member Detail .
​
From a Profile
Open any member’s profile and select the three-dot menu in the upper-right corner.
​
From a Space Member List
Go to the Space Members list and select the three-dot menu next to the person’s name.
