How Do I Add a Quiz to My Course?
Copy page Copy page
Copy page Copy page
On the Launch Plan and above, you’ll see the option to Create Quiz inside the Course feature.
Creating and viewing a Quiz as a Host is available on web and mobile web only.Once you publish a Quiz, your members can view and complete it on web , iOS , and Android .
​
Creating a Quiz
To create a Quiz, go to the “Create” button in a Course.
A Quiz always starts with an introduction page .
You can add a header image, native video, and text to introduce the Quiz and provide instructions. If Course Preview is turned on, this introduction will also appear there.
​
Adding Questions
From the introduction page, you can start adding your questions.
When creating a question, you can attach:
Images
Native video (up to 2GB per file)
GIFs
Emoji
Embedded video (YouTube, Vimeo, etc.) is not supported in Quiz questions.
After adding your question text and any media, add up to five responses and select the one correct answer.
​
Building and organizing your Quiz
Use the “+” icon to add a question above or below the current one.
Or click Add a Question in the upper right corner.
Delete individual responses using the “x” next to each answer.
Delete full questions using the trash icon .
Reorder questions using the three-line drag handle .
You can add up to 100 questions per Quiz.
​
Managing Your Quiz
Under Manage Quiz Settings , you’ll find visibility, unlock, and completion settings—similar to the Course feature.
​
Visibility
Toggle the Quiz on or off to control when members can see it.
​
Unlock Settings
Choose how the Quiz becomes available:
None (unlocked)
Sequential
Timed
Scheduled
​
Showing Correct Answers
You can choose whether members see the correct responses on their results page.
Show correct answers ON : Members can view which answers were correct after they submit.
Show correct answers OFF : Useful if members need to pass before moving on—this prevents them from seeing correct answers before a retake.
​
Completion Options
None : Completion isn’t tracked.
Space Hosts and moderators can see all member responses.
Members see only their own responses.
Completed : Members must complete the Quiz to continue.
Completed and Pass : Members must complete and pass the Quiz to continue.
You can set a Pass Score as a percentage.
​
Additional Settings
You can change the Quiz owner , who must be a Space Host or Space moderator.
You can edit questions or content anytime without affecting previous scores.
Edits only apply to new attempts .
The three-dot menu lets you:
Adjust visibility
Download a CSV of Quiz results
Delete the Quiz
Note: Quiz results currently appear only in the CSV export. They do not appear in Mighty Insights™ or other completion dashboards—this is planned for the future.
​
Member Experience
Members can take Quizzes on web , iOS , and Android .
To preview your Quiz as a member on mobile, use mobile web or temporarily demote your role to Space member.
Members will see a “Ready to take the Quiz?” prompt and a Start button.
During the Quiz:
Members can see their progress.
They can go back and change answers before submitting.
They cannot skip questions.
They must answer questions in order.
Responses are automatically saved , so they can leave and return anytime.
After submitting:
Members see their results, including any completion requirements.
Members can retake the Quiz immediately or anytime after—there is no limit on attempts.
If you edit a Quiz while a member is taking it, they’ll receive a pop-up letting them know they need to restart.
Once added to a Course, members can bookmark the Quiz for quick access.
​
Additional Notes
Only one Instructor can be assigned per Quiz at a time.
Commenting is not supported on Quizzes.
You can edit or add questions even after members have started taking the Quiz.
If you make edits while someone is taking it, they’ll be prompted to restart .
You’ll see how many members will be affected before confirming changes.
Quizzes cannot be duplicated yet.
If you duplicate a Space, the Quizzes inside it will not be duplicated (coming soon).
