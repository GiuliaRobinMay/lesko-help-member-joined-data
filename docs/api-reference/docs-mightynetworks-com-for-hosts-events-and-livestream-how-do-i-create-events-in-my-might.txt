How Do I Create Events in My Mighty Network?
Copy page Copy page
Copy page Copy page
The Events feature (available on the Launch Plan and up) lets you create standalone or ongoing events. The Single Event feature (available on the Launch Plan and above) is for one-time events.
Both can be used for virtual or in-person events and can be enabled in any Space.
​
How to Enable Events
Go to the gear icon in your Space.
Select Space Features > Events .
You can:
Rename the “Events” tab to something custom (this name will appear in the Space at the top)
Choose whether only Hosts and Moderators or all Members can create events.
​
How to Create an Event
Once Events are enabled, click the Create to make one.
You can customize:
Title of the Event
Start and end time (with time zone)
Online Events show in each member’s local time.
For Local Events, you can note if the event’s time zone differs.
Whether it’s a Repeat Event
Images or thumbnails
Description (can include text, media, files, and embeds—just like an Article )
If you have the AI “Make it Better” feature, just highlight your text to use it.
Event Type:
[Network Name] Livestream
Zoom
External Livestream: use this for any other meeting type
Text Chat
Manage RSVP options
Live indicator (on or off — applies to all events in a series)
If you want the Event to immediately show in the Feed when it’s posted
When publishing, you can:
Notify members immediately , or
Schedule it for later (Single Events can’t be scheduled, but you can hide the tab until ready).
Note: Once an Event is created, the Event Host cannot be changed.
​
Single Events
To enable the Single Event feature:
Go to Space Admin (gear icon) > Features and toggle it on.
You can:
Edit the Event
Change the Display Name of the tab
Toggle visibility on or off
When editing, you can customize
Title of the Event
Start and end time (with time zone)
Online Events show in each member’s local time.
For Local Events, you can note if the event’s time zone differs.
Images or thumbnails
Description (can include text, media, files, and embeds—just like an Article )
If you have the AI “Make it Better” feature, just highlight your text to use it.
Event Type:
[Network Name] Livestream
Zoom
External Livestream: use this for any other meeting type
Text Chat
Manage RSVP options
Live indicator (on or off — applies to all events in a series)
When publishing, you can:
Notify members immediately , or
Schedule it for later (Single Events can’t be scheduled, but you can hide the tab until ready).
Here’s what the event looks like when finished. It is similar to the Page Feature.
​
Managing Events
In the three-dot menu of any type of published Event, you can:
Mute – Stop receiving notifications for the Event.
Share – Copy a direct link to the Event.
Enable Comments – Turn comments on or off.
Feature In – Highlight the Event in the Welcome/Featured Section or Welcome Checklist .
Recommend – Pin the Event to the top of the Feed.
Send a Message – Message Event attendees.
Download RSVPs – Export the attendee list (you will get an email with the list)
Event Settings – Adjust details like RSVPs, live indicator, or Feed visibility.
Edit – Update the Event’s content or visuals.
Duplicate Event
Move to Another Space – Transfer the Event to a different Space with Events enabled.
​
Duplicating Events
You can duplicate an Event to reuse its:
Title
Description
Imagery
Settings
Then edit details and publish it in the same Space or another one that also has Events enabled.
​
Where Events Appear
Published Events show up in the Events tab of the Space (except Single Events).
You can expand a calendar view to see all Events in that Space.
If the Global Events feature is enabled, members see all Events across Spaces in one list, in date order.
Tabs let you filter:
Nearby Events (based on your profile location)
Past Events
Your Events (you’ve RSVP’d to)
In the calendar view, Events are color-coded by Space .
​
Event Reminders
Members who RSVP will automatically get reminders:
Online Events: 10 minutes before start time
Local Events: 24 hours and 2 hours before
Virtual event reminders link to the event in Mighty Networks (not directly to Zoom or other platforms)
​
Event Ticketing
On the Launch Plan or higher, you can create a Single Event and charge for that Space by creating a plan!
