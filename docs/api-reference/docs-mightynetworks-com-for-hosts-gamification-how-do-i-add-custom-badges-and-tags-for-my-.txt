How Do I Add Custom Badges and Tags for My Members?
Copy page Copy page
Copy page Copy page
Tags and Badges are powerful ways to recognize, organize and celebrate your members. They can help you segment your community or highlight milestones—all within your Mighty Network.
​
Who Can Use Tags and Badges
Network Hosts and Network moderators on the Launch Plan and above have access to unlimited Tags and Badges on web and mobile.
​
Badges
Badges are visible to everyone in your Mighty Network.
Use them to celebrate achievements, milestones, or actions—like completing a Course, referring members, or hitting engagement goals. There’s no limit to how many creative ways you can use them.
​
Create a New Badge
Go to Admin > Engagement > Badges.
Toggle the Badges feature on (if it isn’t already). If the feature is toggled off, Badges won’t be visible anywhere in your Mighty Network—even to Hosts and moderators.
Click Create Badge and enter:
Badge Name: 40-character limit
Badge Description: 75-character limit
Badge Image: 256x256 pixels (will resize to 24x24 pixels in your Network). Note: Every Badge must have an image.
You can also:
Click Suggestions for an AI-generated Badge image.
Use our Canva Badge Template to design your own.
​
Add Badges to Members
You can assign a Badge to any role—Host, moderator, or member—and to an unlimited number of people.
Members receive email, in-app, and push notifications (if enabled) when they earn a Badge.
You can add a Badge in several ways:
From the Manage Badges page: Click the three-dot menu next to a Badge, then select Add Badge to Members.
From the Network or Space Member List: Select members (or all) > choose Bulk Actions > Add Badge.
You must be both a Network Host/moderator and a Space Host/moderator to use bulk actions in a Space.
From a specific member’s profile:
Open the three-dot menu and choose Add Badge.
From the member detail page:
Click the + icon under Badges
​
Remove Badges
From the Network Member List: select members > Bulk Actions > Remove Badge.
From a Member Detail Page : hover over a Badge and click the x.
​
Manage Badges
Each Badge includes a three-dot menu where you can:
Edit Badge
See Members
View Automations
Add Badge to Members
Delete Badge
You can also automate awarding and removing Badges when members complete specific actions in your Mighty Network.
​
View Member Badges
Badges appear on every member’s profile.
Up to 15 Badges display on a profile.
Click More to view the full list if a member has more than 15.
Click any Badge to open a modal showing the Badge name, description, and how many members have earned it.
Select See members to view the full list—filterable by Top , Near You , Newest , and Online .
You can also search for Badge names using the global search bar.
​
Tags
Tags are internal-only tools for segmenting and organizing your members. They’re visible to Hosts and moderators but not to members themselves.
Use Tags to group members—for example:
Members at risk of churning
Potential mentors
Active participants in a program or challenge
​
Create a New Tag
Go to Admin > Members > Tags.
Toggle the Tags feature on (if it isn’t already). If the feature is toggled off, Tags won’t appear anywhere in your Mighty Network.
Type the Tag name in the top bar (40-character limit) and click Create.
​
Add Tags to Members
You can assign Tags to any role—Host, moderator, or member—and to unlimited members. Each member can only have one instance of a Tag at a time.
You can add a Tag in several ways:
From the Manage Tags page: Click the three-dot menu next to a Tag, then select Add Tag to Members.
From the Network or Space Member List: Select members (or all) > choose Bulk Actions > Add Tags.
You must be both a Network Host/moderator and a Space Host/moderator to use bulk actions in a Space.
From a specific member’s profile:
Open the three-dot menu and choose Add Tag.
From the member detail page:
Click the + icon under Tags
​
Remove Tags
From the Network Member List: select members > Bulk Actions > Remove Tag.
From a Member Detail Page: hover over a Tag and click the x.
​
Manage Tags
Each Tag includes a three-dot menu where you can:
Edit Tag (update name or description)
See Members (view all members with the Tag)
View Automations
Add Tag to Members
Delete Tag
​
Where Tags Appear
Tags are visible only on the Member Detail Page for Network Hosts and moderators.Members cannot see their assigned Tags.
