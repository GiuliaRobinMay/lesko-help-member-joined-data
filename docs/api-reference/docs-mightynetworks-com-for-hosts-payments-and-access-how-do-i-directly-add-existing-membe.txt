How Do I Directly Add Existing Members to My Network or Spaces?
Copy page Copy page
Copy page Copy page
With the Direct Add feature, Network Hosts and moderators can instantly add existing members to Spaces or the Network without sending invites or requiring any action from members.
​
Use Direct Add to:
Give full members immediate access to one or more Spaces
Upgrade limited members to full Network access
Automate membership assignments through Automations or Zapier
Important Notes:
Only Network Hosts and moderators can use this feature.
Only members who already have accounts in your Mighty Network can be directly added to Spaces or the Network.
If a member later joins a plan that includes the Space, their access becomes tied to the plan.
Adding will bypass plan requirements (paid or free), screening questions, approvals, or member actions.
We do not support directly adding to a plan. Consider moving members to plans instead.
Direct Add does not add members to plans, so any plan gates do not apply when directly adding members.
If a member leaves a Space they were directly added to, they lose the ability to rejoin it and must be added again by the Host or join through another route.
If you are adding a large number of members, it may take a while for them to be added. You will get a notification when they have all been added successfully.
If you add a Network Host to a Space, they will join as a  Space Host .
​
How Do I Directly Add a Member to My Network or Spaces?
You have three options:
Add a single member
Add members in bulk
Use Mighty Automations or Zapier to add a member
​
Add a Single Member
Step 1: Open the Member List
Go to Admin > Members > Member List .
Step 2: In the member list, select the three-dot menu next to the member’s name.
Whether you can directly add a member to Spaces or the Network depends on their member type.
You can add:
“Add to Network” will show if the member is a limited member.
“Add to Spaces” will show if the member is a full member .
​
Add Members in Bulk
Step 1: Open the Member List
Go to Admin > Members > Member List .
Step 2: Select multiple members in the member list
Click the “Bulk Actions” menu.
Select “Add to Network” to upgrade limited members to full member s.
Select “Add to Spaces” to give full member s access to one or more Spaces.
If you are adding members to Spaces, you can select multiple Spaces to add them to.
Bulk Add makes it easy to onboard new groups or reorganize members across Spaces!
​
Notifications
As a Host, you will receive email and push notifications (if enabled) when:
Members have received access to Spaces and/or the Network
Members were not successfully added.
Members will also receive notifications when they have been added to Spaces or the Network.
​
Automate Directly Adding Members
You can use Automations or Zapier to add members automatically.
Automations:
Actions
Add to Network (limited members only)
Add limited members to the Network immediately, skipping the invite flow.
Add to Space(s) (full members only)
Adds full members to Space(s) immediately, skipping the invite flow.
Zapier Actions:
Direct Add Member to Space
Direct Add Member to Network​ (only limited members) ​ ​​
